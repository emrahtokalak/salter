Bu klasördeki dosyalar gerçek projelerdeki `.vscode/launch.json` ve `package.json` dosyalarının
anonimleştirilmiş örnekleridir (`.vscode/launch.json` → `<repo>/launch.json`, `package.json` → `<repo>/package.json`).
Keşif/çeviri testleri bu dosyalara karşı çalışır; emoji'li adlar, JSONC yorumları, compounds ve
reload argümanları gibi gerçek dünyadaki biçimler bilerek korunmuştur.
